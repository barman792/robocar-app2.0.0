# اپ اندروید RoboCar — نسخه‌ی 2.0.1

اپ یک «پوسته» است؛ کل رابط در `app/src/main/assets/index.html` است (همان صفحه‌ای که خود ماشین هم در `http://192.168.4.1` نشان می‌دهد). برای همین بدون اینترنت کار می‌کند و حالت نمایشی (Demo) هم دارد.

## چه چیزی در 2.0.1 عوض شد
* لوگوی جدید (ماشین با امواج رادار)، آیکن‌های تطبیقی اندروید (Adaptive + Themed) و صفحه‌ی شروع متحرک.
* گرافیک تازه: نمای ماشین از بالا با چراغ‌ها و وضعیت چرخ‌ها، دسته‌های گاز و فرمان با نوار رنگی، آیکن‌های برداری، افکت‌های نرم.
* چیدمان تمام اندازه‌های صفحه (گوشی کوچک افقی، عمودی، تبلت) بدون بیرون‌زدگی.
* رفع چند ایراد: بسته‌شدن درست ارتباط هنگام رفتن اپ به پس‌زمینه، پنجره‌ی ثبت کارت فقط روی گوشی‌ای که شروع کرده، و …
* فریم‌ور تغییری نکرده است (همان 2.0.0 که روی برد دارید).

## ساخت APK (بدون Android Studio)
1. پوشه‌ی `RoboCarApp` را به یک مخزن GitHub بفرستید.
2. تب **Actions** › «Build APK» › Run workflow.
3. فایل `RoboCar-apk` (حاوی `app-debug.apk`) را از Artifacts دانلود و نصب کنید.

## استفاده
* گوشی را به وای‌فای **RoboCar** وصل کنید (رمز پیش‌فرض `robocar1234`). اگر پیام «بدون اینترنت» آمد، «Stay connected» را بزنید.
* ماشین بعد از برق‌دادن قفل است: کارت را نزدیک ماژول RFID بگیرید (یا «روشن با رمز»).
* ثبت کارت و کارهای مدیریتی با رمز مدیر (پیش‌فرض `Barman@1234`).
* «حالت نمایشی» ماشین مجازی را برای امتحان اپ بدون ماشین فعال می‌کند (با زدن روی آیکن کارت، ماشین روشن می‌شود).
* وقتی اپ به پس‌زمینه می‌رود، ماشین خودکار می‌ایستد.

## پوشه‌ها
| مسیر | توضیح |
|---|---|
| `app/` | پروژه‌ی اندروید |
| `ui_source/` | سورس رابط. بعد از تغییر: `python3 ui_source/build.py` (فایل داخل APK را هم به‌روز می‌کند) |
| `branding/` | لوگو (SVG و PNG ۵۱۲) |
| `extras/web_ui.h` | اختیاری: اگر می‌خواهید صفحه‌ای که خود ماشین نشان می‌دهد هم جدید شود، این فایل را جای `RoboCar/web_ui.h` در پوشه‌ی فریم‌ور بگذارید و دوباره آپلود کنید (لازم نیست؛ اپ خودش رابط جدید را دارد) |
